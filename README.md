## Ticketeer

### AI-powered ticket generation for teams with mixed experience levels
Ticketeer analyzes your codebase and breaks down project goals into scoped, classified tickets — so team leads can assign the right work to the right people.

### How it works
- Connect a repo — paste a GitHub URL
- Describe your goal — "Add OAuth2 with Google and GitHub"
- Get scoped tickets — each classified by complexity (Beginner → Advanced) and priority (Critical Path → Nice-to-Have)

Beginner tickets include step-by-step guidance and file references. Advanced tickets are concise and assume context. Every ticket explains why it's rated the way it is.

### Built for
Engineering clubs, open-source orgs, and any team where a senior lead needs to onboard junior contributors without spending hours scoping work manually.


### Tech stack
React · Tailwind · FastAPI · GEMINI API · Chroma · GitHub API
